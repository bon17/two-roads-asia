# 문제 은행 (검토용 초안)

- 출처: 수업 슬라이드 2판(2026-11-18) · 학습지 「중국과 일본의 국민 국가 건설 운동」(교과서 164~169쪽)
- `[보충]` 표시는 교과서 밖 내용(슬라이드 보충 장)이다. 빼고 싶으면 지우면 된다.
- 문제 유형: **객관식**(보기 4개), **OX**, **순서**(태블릿에서 눌러 순서대로 고르기). 모두 자동 채점된다.
- 검토하실 것: 틀린 내용, 너무 쉽거나 어려운 문제, 빼거나 더할 문제
- **점검 완료 (2026-11-24)**: 슬라이드 2판·학습지와 한 문제씩 대조했다. 사실 오류는 없었다. 아래처럼 고쳤다.
  - 1번: 슬라이드대로 '18세기 중엽 이후'로 고침
  - 16번: 보기를 '~의 진압'으로 고쳐 실패 까닭임을 분명히 함
  - 30번: 태평천국(1851~1864)이 양무운동(1861~)과 겹쳐서 '시작한 순서'라고 밝힘
  - 42번: 배우지 않은 함대(무적함대·북양 함대·발트 함대) 대신 수업에 나온 말로 오답 보기를 바꿈
  - 64번: 자유 민권 운동도 같은 시기라 헷갈릴 수 있어서 오답 보기를 태평천국 운동으로 바꿈
  - 머지 레시피: 사실과 다른 인과(헌법 → 청일 전쟁, 난징 조약 → 제2차 아편 전쟁)와 같은 말 반복(쑨원 + 민족·민권·민생 → 삼민주의)을 고침
  - 주의: 교과서 확인 문제 4("부국강병을 목표로 한 개혁은? 양무운동/메이지 유신/…")는 슬라이드에서 양무운동의 목표도 부국강병이라 헷갈릴 수 있어서 문제 은행에 넣지 않았다

- **영사 재판권**: "이 카드의 뜻은?" ① 우리나라 사람의 죄는 우리 영사가 재판한다 ② 다른 나라 조건을 저절로 받는다 ③ 관세를 혼자 못 정한다 → **①**
- **관세 협의**: ① 수입품 세금을 혼자 정하지 못한다 ② 상대가 죄를 지어도 재판 못 한다 ③ 항구 5개를 연다 → **①**
- **최혜국 대우**: ① 상대가 남에게 주는 좋은 조건을 우리도 저절로 받는다 ② 상대 군대가 수도에 머문다 ③ 땅을 넘겨받는다 → **①**

## 머지 모드: 중국판 11단계 (수박게임 규칙)
같은 카드 둘이 만나면 다음 단계로 바뀐다. 공이 커지는 순서가 곧 역사 순서다. 합쳐질 때 아래 문장이 한 줄 뜬다.
처음 떨어지는 카드는 1~4단계뿐이고, 4단계는 드물게 나온다. 11단계 둘이 만나면 둘 다 사라지고 큰 보너스를 받는다.
★는 수업 키워드다(중국 6개). 일본판은 만들지 않는다.

| 단계 | 카드 | 합쳐질 때 뜨는 문장 |
|---|---|---|
| 1 | 차 | (처음부터 떨어짐) |
| 2 | 은 | 영국은 청의 차를 사고 값을 은으로 냈다 |
| 3 | 아편 | 은이 모자란 영국이 인도산 아편을 몰래 팔았다(삼각 무역) |
| 4 | ★아편 전쟁 1840 | 임칙서가 아편을 단속하자 영국이 군함으로 공격했다 |
| 5 | 난징 조약 1842 | 진 청이 항구 5개를 열고 홍콩을 넘겼다(불평등 조약) |
| 6 | ★태평천국 운동 1851 | 배상금 때문에 세금이 늘자 홍수전이 들고일어났다 |
| 7 | ★양무운동 1861 | 서양 무기에 놀란 관료들이 기술만 들여왔다(중체서용) |
| 8 | ★변법자강 운동 1898 | 청일 전쟁에 지자 캉유웨이가 제도까지 바꾸려 했다 |
| 9 | ★의화단 운동 1899 | 개혁이 100일 만에 멈추고 열강의 침탈이 심해지자 '부청멸양'을 외쳤다 |
| 10 | ★신해혁명 1911 | 철도 국유화에 반발해 우창에서 신식 군대가 봉기했다 |
| 11 | 🏁 중화민국 1912 | 쑨원이 중국 최초의 공화국을 세웠다 |
